# LapSimLab 圈速模擬

桌面版使用繁體中文介面，GitHub Pages 網頁版使用英文介面。兩個版本共用 `new/lapsim` 的準穩態速度規劃模型。

## GitHub Pages 網頁版

網頁左側包含輪胎、懸吊與車體、馬達、煞車、空力、賽道與圈速求解設定。展開分組後可調整參數、選取本機資料檔或下載內建範例。切換模型時只顯示適用的欄位，切回原模型會保留先前的輸入。右側可切換賽道、距離與時間圖，也能匯出逐點訊號 CSV。

求解在瀏覽器執行，選取的資料檔留在本機。Pyodide 和 NumPy 由 GitHub Pages 一併提供。

- 在 **Simulation Inputs** 點選 **Import Vehicle Initial Settings**，開啟 Vehicle Initial Sizing Lab 匯出的 `Vehicle_initial_settings.json`。網頁會填入 **Suspension and Body** 與 **Brakes**，自動選用質點模型及等效機械利益煞車。**Motor** 的 **Fixed Gear Reduction Ratio** 採用 Initial Sizing 的加速與極速減速比平均值。網頁初次開啟、恢復預設及匯入時，輪胎使用率皆設為 70%，可再手動調整。
- 匯入的懸吊參數可在切回逐輪模型後查看。LapSimLab 以後／前 Heave 剛性比作為 Heave 與 Roll 的共用比例，並以兩軸平均值表示輪胎垂直剛性。煞車機械利益以指定減速度所需的總煞車力除以踏力計算。若舊版匯出檔缺少原始設計參數，煞車只匯入前軸比例，減速比沿用目前設定。
- 在左欄展開 **Motor**、**Aerodynamics** 或 **Tires**，按組內的曲線按鈕即可開啟小視窗。按 **Close** 或 Esc 即可回到原本的圈速結果或 GGV。馬達曲線可讀取 RPM／扭矩 CSV 或按設定的直流電壓查看 LP03 包絡。空力可掃描 Roll／Pitch 並切換力或係數，輪胎可查看四輪合計或單輪的 Fy 峰值與 Fx 上下限。
- 在結果區點選 **GGV** 再按 **Calculate GGV**，即可查看目前車輛設定的加速度包絡。3D 曲面可拖曳旋轉，2D 切片可比較五個代表車速或查看指定車速。同一組設定完成 **Calculate Lap** 和 **Calculate GGV** 後，圖上會疊加粉紅色賽道工作點。可用 **Show Track Operating Points** 切換顯示。
- 在右側選擇 **Model Notes**，可用 **Topic** 查看各模型的計算方法與公式。變更左側的模型選項時，右側說明會同步切換到對應主題。英文說明的 Markdown 原始檔位於 `web/models/`，建置時會把 LaTeX 轉成瀏覽器可直接顯示的 MathML。

推送到 `main` 後，GitHub Actions 會建置並發布網頁。若要在本機預覽，請從儲存庫根目錄安裝網頁建置依賴後啟動預覽，再開啟終端機顯示的本機網址。建置時會下載執行環境。

```powershell
python -m pip install -r LapSimLab/web/requirements.txt
python LapSimLab/web/build.py dist --serve
```

## 桌面版啟動與操作

可將整個 `LapSimLab` 資料夾複製到其他位置使用。

雙擊 `Start-LapSimLab.bat`，或在此資料夾執行 `python run.py`。需要 Python 3.10 以上、Tkinter 和 NumPy，車輛控制模擬另需 Pygame。可執行 `python -m pip install -r requirements.txt` 安裝 NumPy 和 Pygame。

1. 在左側「模擬輸入」捲動查看輪胎、懸吊與車體、馬達、空力和賽道設定。輪胎使用率與傳動效率以百分比輸入，例如輸入 `95` 表示 95%。速度上限以 m/s 輸入。
2. 按「計算」或 **F5**。完成後會開啟右側「訊號檢視」，頂端顯示預估圈速、取樣路徑長度、最高車速與最大橫向加速度，下方預設顯示賽道彩虹圖。
3. 在「訊號檢視」切換至時間或距離圖，可查看速度、縱橫向加速度、四輪輪荷、側傾／俯仰及空力等訊號。可匯出完整 CSV 或只匯出勾選的訊號。

關閉前可按視窗右上角的「儲存設定」，將模型選項、輸入參數、開關和資料檔路徑存成 JSON。下次按「載入設定」選擇該 JSON 即可還原，包含當時被模型選項隱藏的參數。設定 JSON 記錄檔案路徑，因此移動賽道、輪胎或空力等資料檔後，請依畫面提示重新選檔。

## 車輛控制模擬

按主視窗上方的「車輛控制模擬」。新視窗會讀取主視窗當下的車重、偏航慣量、重心與軸距、起始車速和速度上限。驅動力以所選馬達模型在車輛靜止時的全油門輪端力為預設，煞車力以所選煞車模型的最大輪端力為預設。兩者在控制模擬中使用固定力值。前、後軸側偏剛性沿用 Control_Sim 的預設值。

在左側調整車輛參數後按「套用參數」。車速上限取自主視窗，適用於縱向與側向速度合成的實際車速。修改主視窗的設定後，關閉並重新開啟控制模擬即可讀取新數值。點擊右側畫面後，按 ↑ 加速、↓ 煞車、←／→ 轉向。按「重設車輛」會保留已套用的參數，讓車輛回到起點和原朝向，以主視窗的起始車速重新開始。起始車速也受速度上限限制。

啟用主視窗的空力後，控制模擬會套用所選空力模型在零升沉、俯仰與側傾時的阻力。空氣阻力與車速平方成正比，方向與車輛移動方向相反。右側 `Aero Drag` 顯示即時阻力（N）。

滾動阻力沿用主視窗的輪胎設定。超橢圓與摩擦橢圓使用固定滾阻係數乘以車重。Pacejka 依前後軸的靜態輪荷查出每輪滾阻扭矩，再以輪胎自由半徑換算成力並加總。滾阻沿車身縱向抵抗行進，右側 `Rolling Resistance` 顯示即時阻力（N）。

## 敏感性分析

1. 開啟右側「敏感性分析」後，左側會自動套用並鎖定質點、機械利益煞車、啟用固定係數空力、全圈迭代及關閉偏航慣量修正。輪胎、馬達與資料檔仍可選擇。切到其他分頁後，可再次調整已套用的模型設定。
2. 基準欄為唯讀，顯示左側輸入的數值，CL、CD 則顯示所選空力 JSON 的 `CL0`、`CD0`。搜尋區間為「基準 ± M」，再依參數限制縮小範圍。總質量、減速比、煞車機械利益、CL、CD 的 M 預設為基準絕對值的 10%，隨基準更新直到手動修改 M。輪胎使用率與傳動效率的 M 預設為 1 個百分點，搜尋限於 0–100%。M 設為 0 可鎖定該值，CD 搜尋下限為 0。直流電壓僅在 LP03 模式出現，M 預設為 53 V，範圍受查表資料及 600 V 上限限制。
3. 按「開始敏感性分析」，以每次全圈計算的單圈時間為目標。畫面顯示搜尋範圍、基準與目前找到的最快圈速，以及最佳參數組合。「搜尋評估上限」控制搜尋的參數組數，每次圈速計算沿用「計算時間上限」。
4. 「單項圈速效益」以秒顯示基準圈速減去單項圈速。單項圈速只把該列參數改為最佳值，其餘參數維持基準。正值表示縮短圈速，負值表示變慢。參數之間可能互相影響，因此逐項加總可能和整組最佳值的總改善不同。單項比較在搜尋結束後計算。
5. 在「等效值（調整量）」欄勾選要參與等效比較的參數。減速比預設未勾選。所有參數仍會計算單項圈速效益。等效比較以勾選項目中的最小正向單項效益為共同目標，對其中有正向效益的項目重跑單項模擬，估算達到目標的參數值。括號內顯示相對基準的增減量，下方列出實際模擬縮短的秒數。變更勾選後，重新開始敏感性分析即可更新等效值。
6. 按「套用最佳設定並查看圈速」可寫回模型與參數並查看完整結果。若最佳 CL 或 CD 與原始值不同，請先另存包含最佳係數的空力 JSON，程式會用該檔案套用結果。

## 切換模型與求解方式

左側各區塊把模型選單、參數與資料檔放在一起。切換模型時，只顯示適用欄位；切回原模型會保留先前輸入。「馬達」下方有煞車設定，「賽道」下方有圈速求解設定。「恢復預設」會選回原本的 LapSimLab 模型與參數。

- **輪胎**切到摩擦橢圓時，透過「摩擦橢圓 JSON」選擇係數檔。固定係數格式只需 `{"mu_x": 1.77, "mu_y": 1.77}`，兩項都須為正數。逐輪模式也支援原有的擬合 JSON。超橢圓的指數 n 直接讀取所選輪胎 JSON。Pacejka 模式顯示 NPZ 資料表選擇器。
- **滾動阻力**依輪胎模型決定。Pacejka 資料插值一律從所選 NPZ 讀取滾阻。超橢圓與摩擦橢圓會顯示「固定滾阻係數」，預設為 `0.015`，輸入 `0` 時滾阻為零。
- **懸吊與車體**中的「輪胎使用率」適用於三種輪胎模式，以同一比例縮放縱向、側向與混合抓地力。輸入 `100` 採用原始抓地力，輸入 `90` 為 90%，輸入 `110` 為 110%。
- **姿態空力**使用包含姿態敏感度的完整 JSON。**固定係數 v²**可使用只含 `CL0`、`CD0` 的 JSON，省略時空氣密度為 1.225 kg/m³、參考面積為 1.2 m²、前軸空力比例為 45%、空力中心高度為 0 m。

右側「模型說明」會即時顯示目前選用的算法、相關參數和輸入檔。可從分頁上方直接跳到指定模組。變更模型後，說明會指出尚未重新計算的圈速仍使用上次的設定。

| 模組 | 選項 |
| --- | --- |
| 輪胎 | JSON 固定摩擦係數或擬合峰值的摩擦橢圓、超橢圓、Pacejka (F_z,F_y) 抓地包絡插值 |
| 煞車 | 等效機械利益、踏板與平衡桿經總泵和卡鉗轉換的液壓煞車 |
| 馬達 | 轉速／扭矩查表、LP03 固定匯流排電壓的最大扭矩包絡查表 |
| 輪載 | 剛性轉移＋輪胎壓縮、整車質點 |
| 空力 | 固定係數的車速平方模型、Heave／Roll／Pitch 姿態空力，另可關閉空力 |
| 賽道 | 原始 LINE／ARC 曲率、以公尺設定尺度的高斯平滑。平滑改變曲率訊號，保留中心線座標與距離 |
| 其他 | 逐輪模式固定依前後軸偏航力矩平衡分配側向力，再依同軸左右輪載比例分配。可選用 Fast Iteration 式偏航慣量彎速修正 |

「賽道 → 圈速求解 → 計算時間上限」預設為 120 秒，輸入 0 可不限時。兩種求解方式共用這個設定，從讀取資料計時到逐點訊號整理完畢。程式在各步驟間檢查時間，逾時會停止並顯示提示。

逾時後按「使用低階模型重算」，可將目前的模型各降一級，並以相同時間上限重算。距離域平滑會改回原始曲率，偏航慣量修正會關閉。降到質點時也會切換到計算較快的固定 μx、μy 摩擦橢圓。視窗底部以「原模型 >> 低階模型」列出變更。若已無可降的選項，介面會建議把最大掃描次數約減半（最低 1 輪），或把取樣間距加倍以減少取樣點。

**全圈迭代**從彎速上限開始，反覆向前掃描加速限制、向後掃描煞車限制。每輪最大車速改變在 0.05 m/s 以內即停止，最多跑設定的輪數。介面會顯示到上限仍未收斂的情況。路徑首尾各自求速。

煞車回掃會保留已符合限制的速度上限。內附賽道以預設模型和固定滾阻係數 `0.015` 計算，全圈迭代為 89.652 秒，從靜止做距離域前向積分為 90.208 秒。

**距離域前向積分**從設定的起始車速出發，依可用縱向加速度以 (v_{i+1}^2=v_i^2+2a_x\Delta s) 推進。預設先做一次煞車前瞻，再單向積分。取消前瞻時，改用當下的煞車能力和到下一個彎速低點的距離估算何時煞車。若車輛來不及降速，結果會保留可達的車速，介面和 `lateral_overspeed` 欄位會指出超出側向速度上限的取樣點。

**質點模式**使用整車總輪載與抓地力。固定摩擦係數直接乘總輪載，超橢圓、擬合摩擦橢圓與 Pacejka 使用四分之一的總輪載和零外傾角查單輪抓地，再加總四輪。完整 CSV 會省略整欄皆為 0 的四輪輪載、單輪扭矩與懸吊訊號。逐輪 Pacejka 可用資料點反推滑移、輪胎力矩及力殘差。兩種求解器都用準穩態局部車輛模型，LP03 選項使用固定電壓包絡。

## 逐點訊號檢視

右側「訊號檢視」只列出本次求解中數值有變化的訊號。點一下清單列即可勾選或取消，最多可同時比較四個訊號。可用中文名稱、欄位名或單位搜尋。重新求解後仍有變化的已勾選訊號會保留。搜尋「車身」可找車身加速度，搜尋 `wheel_omega` 可找四輪角速度。

賽道彩虹圖會依最後勾選的訊號著色，色條顯示該訊號的單位與本圈最小、最大值。清除勾選後會顯示車速。時間與距離圖可疊顯示已勾選的訊號，同單位使用原始刻度，混合單位時各曲線以本圈最小值至最大值換算成 0–100%。點選圖表或拖曳取樣滑桿可查看原始讀值，切換檢視時會保留該取樣點。

「匯出完整 CSV」會輸出摘要與逐點訊號，略過整欄皆為 0 的數值欄位。非零的固定值仍會匯出。「匯出勾選訊號 CSV」會輸出距離 `distance_m`、時間 `time_s` 和勾選訊號的原始數值。兩種 CSV 都會保留每個取樣點，輪序為 FL、FR、RL、RR。

簧上位移 `zs` 與簧下位移 `zu` 以靜態為基準且向上為正，原有 `heave_mm` 以向下為正。`zs` 由 Heave 和合成 Roll／Pitch 換算至車身四角。`zu` 取當前受載半徑減去靜止受載半徑。各角速度與加速度由逐點位移做時間差分。逐輪縱向力、扭矩與踏板命令是按速度規劃與傳動／煞車比例得到的準穩態估算。

四輪相對位移欄位 `zs_minus_zu_*_mm` 為同一輪的 `zs − zu`。相對於靜止狀態，正值表示車身角點與輪心的垂直距離增加，負值表示距離縮短。完整 CSV 也逐點記錄合成側傾 `roll_deg`、合成俯仰 `pitch_deg`，以及由賽道路徑切線估算的航向角 `yaw_deg`。

## 分析工具

輪胎力掃描、馬達曲線與空力掃描可從左側對應設定區塊底部的按鈕開啟。三個子視窗可獨立於圈速計算使用，初次開啟會繪製預設曲線，調整條件後按「更新曲線」。

在右側 **GGV** 分頁按「計算 GGV」，會把從 0 到設定速度上限的 13 個切片連成 3D 曲面。三軸為側向加速度 ay、縱向加速度 ax 和車速。拖曳可旋轉，雙擊重設視角。切到 2D 切片可疊看五個代表車速，或選取單一車速查看峰值。曲面沿用圈速的輪胎、輪載、空力、馬達、煞車與滾阻模型，包含逐輪模式的前後軸偏航力矩平衡。左右掃描範圍依零縱向加速度時的側向上限及側向安全係數決定。GGV 描述固定速度工況，曲率平滑與換向偏航慣量修正屬於圈速路徑計算。0 km/h 切片表示零速參數下的理論能力。

同一組設定完成圈速與 GGV 計算後，兩個版本都會將圈速結果的車速、橫向加速度與縱向加速度畫成粉紅色工作點。3D 和 2D 代表車速疊圖使用全圈取樣點。2D 選單一車速時，顯示車速最接近該切片的取樣點。桌面版可用「顯示賽道工作點」切換顯示。

- **空力掃描**固定車速、Heave 及另一個姿態角，掃描 Roll 或 Pitch。可查看下壓力與阻力、前後軸下壓力或 CL/CD。
- **馬達曲線**顯示目前選用的單馬達轉速／扭矩曲線。選用 LP03 時顯示指定直流電壓下的包絡。圖的範圍以 CSV 內的轉速為準。
- **輪胎力掃描**固定使用車重和重心位置決定的靜態輪載。Roll 只用於換算外傾角，空力和載重轉移皆省略。側向曲線顯示 Fx = 0 時符合前後軸偏航力矩平衡的 Fy 上限，單輪曲線顯示達到整車上限時該輪分到的力。指定橫向加速度只用來計算側向力需求與剩餘的驅動／煞車抓地。任一輪無法提供分到的 Fy 時，該點各輪 Fx 顯示為 0。縱向曲線未套用馬達、煞車或空阻限制。

## 內附輸入資料

### 重建 Pacejka 包絡

`Pacejka_tire_model/` 提供新版輪胎公式與力圖。直接執行輪胎模型時，請使用本機的 `.tir` 參數檔。LapSimLab 執行時以 `input_data/pacejka_envelope.npz` 插值。要從內附的 W8 力圖重建包絡，可在 `LapSimLab` 資料夾安裝 SciPy 後執行：

```sh
python tools/build_pacejka_envelope.py
```

W8 力圖由 Hoosier 43075 R20 W8 候選係數產生，產表條件為 9 psi、外傾角 0°、單輪載重 100–1,400 N。輪胎力查詢超出載重範圍時使用最接近的邊界。該候選係數產出的滾阻為 0。Pacejka 模式若需計入非零滾阻，請選用含有對應滾阻資料的 NPZ。

## 計算範圍

LapSim 以分段中心線的取樣點估算側向抓地上限，再以前後向掃描納入驅動與煞車能力。計時使用取樣點間的平面距離，因此顯示的路徑長度會與 CSV 分段長度加總略有差異。輪胎力查詢沿用原模型的荷重與外傾角擬合範圍。取樣點上限為 25,000，超過時可增大取樣間距。

### 車身側傾與俯仰

在「懸吊與車體」設定輪胎垂直剛性。逐輪模型用它換算受載半徑，質點模型會隱藏此欄位。需要計算車身姿態的模型也會顯示前軸 Roll 剛性（每輪，N/m）、前軸 Heave 剛性（整軸，N/m）與共用的後／前剛性比。後軸 Roll 和 Heave 各自用前軸的數值乘上這個比值。預設 `1.0` 表示前後相同，`1.2` 表示後軸為前軸的 120%。

在「剛性轉移＋輪胎壓縮」模型中，每輪垂直壓縮量取 `δ = max(Fz, 0) / K_tire`。前後軸各自以 `atan2(δ右 − δ左, 輪距)` 算出輪胎側傾，再取兩軸平均並加到懸吊側傾，得到整車 roll。Pitch 則用前後軸平均壓縮差相對於靜止狀態的變化，除以軸距取反正切後加到懸吊俯仰。合成姿態用於空力計算與「車身姿態」圖，camber 依合成 roll 換算。
