# LapSimLab 圈速模擬

獨立的繁體中文桌面工具，沿用 `new/lapsim` 的準穩態速度規劃模型。可將整個 `LapSimLab` 資料夾複製到其他位置使用。

## 啟動與操作

雙擊 `Start-LapSimLab.bat`，或在此資料夾執行 `python run.py`。需要 Python 3.10 以上、Tkinter 和 NumPy。若使用的 Python 尚未安裝 NumPy，可執行 `python -m pip install -r requirements.txt`。

1. 在左側「輪胎、懸吊與車體、馬達、空力、賽道」分頁選模型並調整參數。百分比設定以 0–1 輸入，速度上限以 m/s 輸入。
2. 按「計算」或 **F5**。右側會顯示預估圈速、取樣路徑長度、最高車速與最大橫向加速度。
3. 切換結果分頁查看賽道速度圖、速度曲線、縱橫向加速度、四輪輪荷、側傾／俯仰及空力。按「匯出完整 CSV」可儲存本次計算的所有逐點訊號。

關閉前可按視窗右上角的「儲存設定」，將模型選項、輸入參數、開關和資料檔路徑存成 JSON。下次按「載入設定」選擇該 JSON 即可還原，包含當時被模型選項隱藏的參數。設定 JSON 記錄檔案路徑，因此移動賽道、輪胎或空力等資料檔後，請依畫面提示重新選檔。

## 最佳化模式

1. 在左側選擇輪胎、馬達與賽道，開啟右側「最佳化」。最佳化固定使用質點、機械利益煞車、固定係數空力及全圈迭代。輪胎模型及資料檔沿用左側選擇。
2. 每個參數使用目前值作為基準，搜尋區間為「基準 ± M」，再依參數限制縮小範圍。M 使用該參數的原單位，設為 0 可鎖定該值。輪胎使用率與傳動效率限制在 0–1。直流電壓僅在 LP03 模式出現，範圍受查表資料及 600 V 上限限制。CL、CD 可留空採用空力 JSON。
3. 按「開始最佳化」，以每次全圈計算的單圈時間為目標。畫面顯示搜尋範圍、基準與目前找到的最快圈速，以及最佳參數組合。「搜尋評估上限」控制搜尋的參數組數，每次圈速計算沿用「計算時間上限」。
4. 「單項圈速效益」以秒顯示基準圈速減去單項圈速。單項圈速只把該列參數改為最佳值，其餘參數維持基準。正值表示縮短圈速，負值表示變慢。參數之間可能互相影響，因此逐項加總可能和整組最佳值的總改善不同。單項比較在搜尋結束後計算。
5. 按「套用最佳設定並查看圈速」可寫回模型與參數並查看完整結果。

## 切換模型與求解方式

各分頁把模型選單、參數與資料檔放在一起。切換模型時，只顯示適用欄位；切回原模型會保留先前輸入。「馬達」下方有煞車設定，「賽道」下方有圈速求解設定。「恢復預設」會選回原本的 LapSimLab 模型與參數。

- **輪胎**切到摩擦橢圓時，透過「摩擦橢圓 JSON」選擇係數檔。固定係數格式只需 `{"mu_x": 1.77, "mu_y": 1.77}`，兩項都須為正數。逐輪模式也支援原有的擬合 JSON。超橢圓的指數 n 直接讀取所選輪胎 JSON。Pacejka 模式顯示 NPZ 資料表選擇器。
- **懸吊與車體**中的「輪胎使用率」適用於三種輪胎模式，以同一比例縮放縱向、側向與混合抓地力。`1` 採用原始抓地力，`0.9` 為 90%，`1.1` 為 110%。
- **姿態空力**的係數均從所選 JSON 讀取。切換到**固定係數 v²**時，可覆寫基準 CL、CD，留空則沿用 JSON 的值。

右側「模型說明」會即時顯示目前選用的算法、相關參數和輸入檔。可從分頁上方直接跳到指定模組。變更模型後，說明會指出尚未重新計算的圈速仍使用上次的設定。

| 模組 | 選項 |
| --- | --- |
| 輪胎 | JSON 固定摩擦係數或擬合峰值的摩擦橢圓、超橢圓、Pacejka (F_z,F_y) 抓地包絡插值 |
| 煞車 | 等效機械利益、踏板與平衡桿經總泵和卡鉗轉換的液壓煞車 |
| 馬達 | 轉速／扭矩查表、LP03 固定匯流排電壓的最大扭矩包絡查表 |
| 輪載 | 剛性轉移＋輪胎壓縮、整車質點 |
| 空力 | 固定係數的車速平方模型、Heave／Roll／Pitch 姿態空力，另可關閉空力 |
| 賽道 | 原始 LINE／ARC 曲率、以公尺設定尺度的高斯平滑。平滑改變曲率訊號，保留中心線座標與距離 |
| 其他 | 逐輪模式固定依前後軸偏航力矩平衡分配側向力，再依同軸左右輪載比例分配。滾阻可關閉、用固定係數，或在 Pacejka 模式用表中滾阻。可選用 Fast Iteration 式偏航慣量彎速修正 |

「賽道 → 圈速求解 → 計算時間上限」預設為 120 秒，輸入 0 可不限時。兩種求解方式共用這個設定，從讀取資料計時到逐點訊號整理完畢。程式在各步驟間檢查時間，逾時會停止並顯示提示。

逾時後按「使用低階模型重算」，可將目前的模型各降一級，並以相同時間上限重算。距離域平滑會改回原始曲率，偏航慣量修正會關閉。降到質點時也會切換到計算較快的固定 μx、μy 摩擦橢圓。視窗底部以「原模型 >> 低階模型」列出變更。若已無可降的選項，介面會建議把最大掃描次數約減半（最低 1 輪），或把取樣間距加倍以減少取樣點。

**全圈迭代**從彎速上限開始，反覆向前掃描加速限制、向後掃描煞車限制。每輪最大車速改變在 0.05 m/s 以內即停止，最多跑設定的輪數。介面會顯示到上限仍未收斂的情況。封閉賽道可勾選首尾等速。

煞車回掃會保留已符合限制的速度上限。修正後，內附賽道以預設模型算得 88.162 秒，使用預設模型並從靜止做距離域前向積分則為 88.743 秒。

**距離域前向積分**從設定的起始車速出發，依可用縱向加速度以 (v_{i+1}^2=v_i^2+2a_x\Delta s) 推進。預設先做一次煞車前瞻，再單向積分。取消前瞻時，改用當下的煞車能力和到下一個彎速低點的距離估算何時煞車。若車輛來不及降速，結果會保留可達的車速，介面和 `lateral_overspeed` 欄位會指出超出側向速度上限的取樣點。

**質點模式**使用整車總輪載與抓地力。固定摩擦係數直接乘總輪載，超橢圓、擬合摩擦橢圓與 Pacejka 使用四分之一的總輪載和零外傾角查單輪抓地，再加總四輪。CSV 中保留整車合力，四輪輪載、單輪扭矩及懸吊訊號填 0。逐輪 Pacejka 可用資料點反推滑移、輪胎力矩及力殘差。兩種求解器都用準穩態局部車輛模型，LP03 選項使用固定電壓包絡。

## 逐點訊號檢視

完成圈速計算後，切到右側「訊號檢視」。可用中文名稱、欄位名或單位搜尋，再選擇時間、距離或賽道彩虹圖。彩虹圖依車速著色，單位為 km/h。點選賽道或拖曳取樣滑桿會移動標記並顯示該點的訊號值，切換檢視時會保留同一取樣點。按住 Ctrl 或 Shift 可比較最多四個同單位訊號。

完整 CSV 保留原本的摘要欄位，另附四輪簧上／簧下位移、速度、加速度、輪胎三向力、轉向角、Camber、受載半徑、輪速、馬達轉速、扭矩與踏板命令等訊號。每一列對應圈速模型的一個取樣點，輪序為 FL、FR、RL、RR。

簧上位移 `zs` 與簧下位移 `zu` 以靜態為基準且向上為正，原有 `heave_mm` 以向下為正。`zs` 由 Heave 和合成 Roll／Pitch 換算至車身四角。`zu` 取當前受載半徑減去靜止受載半徑。各角速度與加速度由逐點位移做時間差分。逐輪縱向力、扭矩與踏板命令是按速度規劃與傳動／煞車比例得到的準穩態估算。

四輪相對位移欄位 `zs_minus_zu_*_mm` 為同一輪的 `zs − zu`。相對於靜止狀態，正值表示車身角點與輪心的垂直距離增加，負值表示距離縮短。完整 CSV 也逐點記錄合成側傾 `roll_deg`、合成俯仰 `pitch_deg`，以及由賽道路徑切線估算的航向角 `yaw_deg`。

## 分析分頁

右側的分析分頁可獨立於圈速計算使用。初次開啟會繪製預設曲線，調整條件後按「更新曲線」。

在 **GGV** 分頁按「計算 GGV」，會把從 0 到設定速度上限的 13 個切片連成 3D 曲面。三軸為側向加速度 ay、縱向加速度 ax 和車速。拖曳可旋轉，雙擊重設視角。切到 2D 切片可疊看五個代表車速，或選取單一車速查看峰值。曲面沿用圈速的輪胎、輪載、空力、馬達、煞車與滾阻模型，包含逐輪模式的前後軸偏航力矩平衡。左右掃描範圍依零縱向加速度時的側向上限及側向安全係數決定。GGV 描述固定速度工況，曲率平滑與換向偏航慣量修正屬於圈速路徑計算。0 km/h 切片表示零速參數下的理論能力。

- **空力掃描**固定車速、Heave 及另一個姿態角，掃描 Roll 或 Pitch。可查看下壓力與阻力、前後軸下壓力或 CL/CD。
- **馬達曲線**顯示目前選用的單馬達轉速／扭矩曲線。選用 LP03 時顯示指定直流電壓下的包絡。圖的範圍以 CSV 內的轉速為準。
- **輪胎力掃描**固定使用車重和重心位置決定的靜態輪載。Roll 只用於換算外傾角，空力和載重轉移皆省略。側向曲線顯示 Fx = 0 時符合前後軸偏航力矩平衡的 Fy 上限，單輪曲線顯示達到整車上限時該輪分到的力。指定橫向加速度只用來計算側向力需求與剩餘的驅動／煞車抓地。任一輪無法提供分到的 Fy 時，該點各輪 Fx 顯示為 0。縱向曲線未套用馬達、煞車或空阻限制。

### 重建 Pacejka 包絡

`Pacejka_tire_model/` 內附新版輪胎公式、候選 `.tir` 與力圖。LapSimLab 執行時以 `input_data/pacejka_envelope.npz` 插值。要從內附的 W8 力圖重建包絡，可在 `LapSimLab` 資料夾安裝 SciPy 後執行：

```sh
python tools/build_pacejka_envelope.py
```

W8 力圖取自 `Hoosier_43075_R20_W8_candidate.tir`，產表條件為 9 psi、外傾角 0°、單輪載重 100–1,400 N。輪胎力查詢超出載重範圍時使用最接近的邊界。候選係數產出的滾阻為 0。若要另外計入滾阻，可在輪胎設定選「固定滾阻係數」。

## 計算範圍

LapSim 以分段中心線的取樣點估算側向抓地上限，再以前後向掃描納入驅動與煞車能力。計時使用取樣點間的平面距離，因此顯示的路徑長度會與 CSV 分段長度加總略有差異。輪胎力查詢沿用原模型的荷重與外傾角擬合範圍。取樣點上限為 25,000，超過時可增大取樣間距。

### 車身側傾與俯仰

在「懸吊與車體」設定輪胎垂直剛性。逐輪模型用它換算受載半徑，質點模型會隱藏此欄位。需要計算車身姿態的模型也會顯示前軸 Roll 剛性（每輪，N/m）、前軸 Heave 剛性（整軸，N/m）與共用的後／前剛性比。後軸 Roll 和 Heave 各自用前軸的數值乘上這個比值。預設 `1.0` 表示前後相同，`1.2` 表示後軸為前軸的 120%。

在「剛性轉移＋輪胎壓縮」模型中，每輪垂直壓縮量取 `δ = max(Fz, 0) / K_tire`。前後軸各自以 `atan2(δ右 − δ左, 輪距)` 算出輪胎側傾，再取兩軸平均並加到懸吊側傾，得到整車 roll。Pitch 則用前後軸平均壓縮差相對於靜止狀態的變化，除以軸距取反正切後加到懸吊俯仰。合成姿態用於空力計算與「車身姿態」圖，camber 依合成 roll 換算。
